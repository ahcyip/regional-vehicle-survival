# Regional Vehicle Survival

Analysis of **state-level vehicle survival rates** and **used-vehicle migration**
(net imports/exports between states) for NREL's UVM (used-vehicle migration) work,
built from Experian Vehicles-in-Operation (VIO) data.

## What's here

The whole pipeline and analysis live in **[`survival.qmd`](survival.qmd)** — a Quarto
document that goes from raw VIO snapshots to survival curves, state-vs-national
net-import rates (a replication + extension of Greene/UTK's method), and the figures
(geofacet survival panels, scatter comparisons, Sankey/leaflet migration maps).

```
survival.qmd                      * main pipeline + analysis (canonical)
investigate_vintaged_stock.qmd    side analysis: per-year vintaged stock
R/
  eia_2023_surv.R                 standalone: AEO 2023 survival-curve comparison
data/
  raw/                            committed source inputs (see data/README.md)
  *.csv                           GENERATED by survival.qmd - git-ignored
docs/
  reports/  presentations/  papers/  reference/   write-ups & decks
archive/                          superseded scripts, kept for reference (see archive/README.md)
```

## Setup

Requires **R (>= 4.2)** and **Quarto**. Install dependencies (listed in
[`DESCRIPTION`](DESCRIPTION)):

```r
install.packages("renv")   # recommended for a reproducible, pinned environment
renv::init()               # then renv::snapshot() to lock versions
# - or, quick start without renv:
install.packages(c("tidyverse", "readxl", "patchwork", "scales", "geofacet",
                   "gganimate", "gifski", "plotly", "htmlwidgets", "htmltools",
                   "networkD3", "leaflet", "mapview", "sf", "tigris",
                   "RColorBrewer", "skimr", "here"))
```

Then open `regional-vehicle-survival.Rproj` and render:

```r
quarto::quarto_render("survival.qmd")
```

## Data

- **Committed input:** `data/raw/StateNationalSurvivalRateDifferences19Mar2026NewMethod.xlsx`
  - the Greene/UTK state-vs-national net-import workbook, read by the net-imports section.
- **External input (not in this repo):** annual Experian VIO snapshots,
  `exp_<year>_stock_interim.csv`, expected under a local `from eagle/experian/` path.
  See [`data/README.md`](data/README.md) for provenance and the path variable to set.
- **Everything in `data/*.csv` is generated** by `survival.qmd` and git-ignored; it is
  reproduced by rendering the document. Figures, HTML widgets, and the `est net flows/`
  outputs are likewise generated and ignored.

## Outputs

Rendering produces survival CSVs in `data/`, figure PNGs, and interactive HTML
(Sankey/leaflet migration maps under `est net flows/`) - all git-ignored and
regenerated on demand.
