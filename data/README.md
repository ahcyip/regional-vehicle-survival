## External inputs — NOT in this repo

These are large and/or restricted and live outside the repo:

| File pattern | What it is | Where it's expected |
|--------------|-----------|---------------------|
| `exp_<year>_stock_interim.csv` (2014–2025) | Annual Experian Vehicles-in-Operation (VIO) snapshots: stock by state × vehicle type × model year. | Local path `from eagle/experian/` (set the `directory` / path variable near the top of `survival.qmd` Phase 1). |

To reproduce the analysis you need the Experian interim CSVs on your machine and the
path variable in `survival.qmd` pointed at them.

## Generated files (git-ignored)

Everything else that lands in this folder — `pipeline_*_survival_*.csv`,
`national_14to25_survival.csv`, `state_14to25_survival.csv`, `greene_intermediate.csv`,
`net_imports_long.csv`, `net_imports_summary.csv`, etc. — is **written by
`survival.qmd`** and is git-ignored. It is regenerated by rendering the document, so it
is not versioned here.
