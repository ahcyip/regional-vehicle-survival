# Data

```
data/
├── raw/          # Immutable raw input data — never modify files here
└── processed/    # Cleaned, transformed data ready for analysis
```

## Adding Data Files

1. Copy raw data files into `data/raw/`.
2. If a file is large (>10 MB) or proprietary, add an entry to the table above with a note about how to obtain it — do **not** commit the file itself.
3. If the file is small and non-sensitive, you may add an exception in the root `.gitignore` to allow it to be committed.
