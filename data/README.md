## `raw/census_state_to_state/` — Census state-to-state migration flows (committed)

U.S. Census Bureau, ACS 1-year **State-to-State Migration Flows** tables, downloaded
unmodified on 14 Oct 2026 from
<https://www.census.gov/data/tables/time-series/demo/geographic-mobility/state-to-state-migration.html>.
Read by `population_migration.qmd`.

| File | ACS year | Notes |
|------|----------|-------|
| `State_to_State_Migrations_Table_2014.xls` … `_2019.xls` | 2014–2019 | wide matrix, two header blocks |
| `State_to_State_Migrations_Table_2021.xls` | 2021 | same layout |
| `State_to_State_Migration_Table_2022_T13_updated_2024_06_27.xlsx` | 2022 | Census re-release correcting a Connecticut processing error |
| `State_to_State_Migration_Table_2023_T13.xlsx` | 2023 | wide matrix, single header block |
| `State_to_State_Migration_Table_2024_T13.xlsx` | 2024 | long format + supplemental total sheets; 285 small cells suppressed ("N") |

No ACS 2020 table exists (standard 2020 1-year estimates were not released), and ACS
2025 was not yet published at download time.

## External inputs — NOT in this repo

These are large and/or restricted and live outside the repo:

| File pattern | What it is | Where it's expected |
|--------------|-----------|---------------------|
| `exp_<year>_stock_interim.csv` (2014–2025) | Annual Experian Vehicles-in-Operation (VIO) snapshots: stock by state × vehicle type × model year. | Local path `from eagle/experian/` (set the `directory` / path variable near the top of `survival.qmd` Phase 1). |

To reproduce the analysis you need the Experian interim CSVs on your machine and the
path variable in `survival.qmd` pointed at them.

## Generated files (git-ignored)

Everything else that lands in this folder — `pipeline_*_survival_*.csv`,
`national_14to25_survival.csv`, `state_14to25_survival.csv`, `greene_intermediate.csv`,
`net_imports_long.csv`, `net_imports_summary.csv`, etc. — is **written by
`survival.qmd`** and is git-ignored. It is regenerated by rendering the document, so it
is not versioned here.
